# Goutham & Sindhuja Wedding Website

## Run in VS Code
1. Extract the ZIP.
2. Open the `goutham-sindhuja-wedding` folder in VS Code.
3. Open Terminal → New Terminal.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL shown by Vite (normally http://localhost:5173).

## Main files
- `src/App.jsx`: React invitation page
- `src/App.css`: page design
- `src/index.css`: global styles and fonts
- `src/main.jsx`: React entry point
- `src/assets/`: images used by the page
